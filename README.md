# NaidaBureau

**Портфоліо Наталії Найди — дизайнерки й фулстак-розробниці.**
Застосунки, сайти й віджети: дизайн — мій, код — з AI, контроль — мій.

🔗 **Сайт:** https://naidabureau.github.io

## Що всередині

| Сторінка | Що це |
|---|---|
| [`index.html`](index.html) | Головна «Кіно і 3D»: тисячі частинок складаються у знак `<N/>`, DESIGN, CODE, телефон і логотип |
| [`os.html`](os.html) | **NaidaOS** — власна «операційна система» з вікнами, терміналом і проєктами як програмами |
| [`editor.html`](editor.html) | **Живий редактор** — сайт збирається на очах, можна тягати шари, міняти кольори й бачити код |
| [`game.html`](game.html) | **Naida Quest** — гра на 4 рівні (ідея → дизайн → код → запуск) і знижка, яка тікає |
| [`concepts.html`](concepts.html) | Порівняння всіх чотирьох концепцій |

Чистий HTML, CSS і JavaScript, без фреймворків і збірки. Кожна сторінка — один файл. Працює на комп'ютері й телефоні.
